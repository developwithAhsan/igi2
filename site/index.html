About the game

I.G.I. 2: Covert Strike is a tactical first-person stealth shooter built around infiltration, reconnaissance and carefully planned combat. Move through hostile territory, use the environment, manage ammunition and complete objectives with precision.

This is an independent fan-made website and is not affiliated with the original publisher. The browser runtime recognises I.G.I. 2 installations and can load and render its levels. Original game files are not hosted here.

Frequently asked questions

Quick mission support
Can I play IGI 2 directly in my browser?
Choose the I.G.I. 2 PC folder containing igi2.exe. The browser runtime can load and render I.G.I. 2 levels, but this engine revision does not yet implement the player character, weapons or AI, so levels currently open in free-camera mode. WebGPU is required.
Do I need my own game files?
Yes. Choose a game installation you are legally entitled to use. The website does not host, bundle or redistribute original game data.
Why does the Play Game button ask me to choose a folder?
The current browser flow reads a supported installation from your device. The selected files stay in your browser session and are not uploaded to this website.
Which browser should I use?
Use an up-to-date Chrome or Edge browser with WebGPU and hardware acceleration enabled. Your graphics hardware and browser version can affect compatibility.
How do I enter fullscreen?
Press the Fullscreen button below the game frame. Press Escape or use your browser's fullscreen control to leave fullscreen mode.
Are game settings available?
The Settings panel is a visual placeholder for now. Resolution and graphics options will be connected when the browser runtime exposes the required controls.
